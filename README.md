# Autocomplete and Spell Corrector

A Python-based web application that provides word autocomplete
using a Trie and spelling correction using dynamic programming.

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript

## Main Features

1. Prefix-based autocomplete
2. Frequency-based suggestion ranking
3. Spell correction using edit distance
4. Local web application

## Run the Application

1. Create and activate a Python virtual environment.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python app.py`.
4. Open the local address shown in the terminal.

## Data Structures and Algorithms

- Trie
- Hash Map
- Dynamic Programming
- Sorting
